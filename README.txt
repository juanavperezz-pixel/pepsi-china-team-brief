PEPSI IN CHINA — TEAM CASE BRIEF

This is a single-page website with no external libraries, database or server needed.
Open index.html locally to preview. Quiz, timeline, and notes work in modern browsers.
Notes are stored in each visitor's browser; they are NOT shared or synchronized.

PUBLISH (NETLIFY)
1. Visit https://app.netlify.com/drop
2. Drop this entire unzipped folder (or this ZIP if the drop page accepts it).
3. Netlify returns a live link. Copy it and send to teammates.

PUBLISH (GITHUB PAGES)
1. Create a new GitHub repository, for example pepsi-china-team-brief.
2. Upload the files from this folder (index.html and .nojekyll and robots.txt) to the repo root.
3. In Settings > Pages, choose Deploy from a branch, main, /(root), and save.
4. The address will resemble https://YOUR-USERNAME.github.io/pepsi-china-team-brief/ .

IMPORTANT PRIVACY AND COPYRIGHT
By default, Netlify Drop and ordinary GitHub Pages publish publicly accessible pages.
An unlisted URL, robots.txt and noindex are NOT password protection.
Do not upload the licensed case PDF or extensive verbatim extracts. The team should
access the case through individual authorized course materials.
For truly team-only access, use an authenticated private hosting setup.
Netlify basic shared-password protection currently requires a qualifying paid plan.

The study brief is not hosted by this package until you upload it to a host.
